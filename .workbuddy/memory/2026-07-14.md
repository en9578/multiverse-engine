## 系统架构阿里巴巴规范优化

用户要求优化架构严格符合阿里巴巴Java开发手册，产出 `architecture.md`（与 design.md 第2/3/7/8章冲突以本文档为准），并已在 design.md 2.1 加指引。
8 项关键修正：
1. **补 Manager 层**（四层 controller/service/manager/dao），百炼6模型封装统一归入 BailianManager（第三方封装归 Manager 层）
2. 包结构规范：service/manager 接口+impl 分离，包名小写单数，DAO 命名
3. 领域模型五层分离：DO/VO/DTO/BO/Query，禁止 DAO 返回 HashMap
4. MySQL 规约：补 gmt_create/gmt_modified，id bigint unsigned，is_xxx tinyint，索引 uk_/idx_ 命名单表≤5，给出 task/product_image 合规 DDL
5. 线程池用 ThreadPoolTaskExecutor 显式参数（禁 Executors），@Async("pipelineExecutor")/("bailianExecutor") 指定 Bean，命名线程+拒绝策略
6. 统一 Result<T> + BusinessException + ErrorCodeEnum + @RestControllerAdvice 全局异常
7. 状态机/错误码枚举化（TaskStatusEnum/StageEnum/ComplianceStatusEnum/ErrorCodeEnum），禁魔法值
8. 日志 SLF4J 占位符 {}、异常带堆栈、生产禁 debug、@Transactional 不注接口且不含百炼远程调用
附合规代码骨架（Controller/ServiceImpl/BailianManagerImpl/TaskDAO）+ 单测 AIR 原则 + 12 项自查清单
另用 Visualizer 绘制四层架构分层图（Manager 层高亮标"规范关键"）
